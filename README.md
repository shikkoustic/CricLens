# CricLens

Cricket batting analysis from video: find the batter, extract body joints from ball release to follow-through,
classify the shot, score technique per body part, and give coaching feedback.

- Project context and rules: [`CLAUDE.md`](CLAUDE.md)
- Status and next steps: [`PROGRESS.md`](PROGRESS.md)
- New teammate setup: [`docs/TEAMMATE_SETUP.md`](docs/TEAMMATE_SETUP.md)
- Dataset sources and licences: [`docs/DATASHEET.md`](docs/DATASHEET.md)
- Image and Video Processing experiments: [`docs/iva/`](docs/iva/)

Data is not in this repository (broadcast-derived, academic use only). It lives in private Kaggle datasets;
see `scripts/fetch_data.sh`.
